# Student Grade Calculator

## Module 2 - Python Mini Project

This project is a beginner-friendly Python application developed as part of **Module 2 - Python Mini Project** for the Codomax Digital Solutions internship.

The Student Grade Calculator accepts a student's name and marks for three subjects, calculates the total marks and average, and assigns a grade based on the average score.

---

## Project Objective

The main objective of this project is to apply the Python programming concepts learned in Module 1 to build a simple real-world application.

The project demonstrates the use of:

- Variables
- User input
- Data types
- Arithmetic operations
- Conditional statements
- Basic Python programming concepts

---

## Features

- Accepts the student's name
- Accepts marks for three subjects
- Calculates total marks
- Calculates average marks
- Determines the student's grade
- Displays the final result in a simple format

---

## Subjects

The program currently accepts marks for:

1. Mathematics
2. Science
3. English

Each subject is evaluated out of 100 marks.

---

## Grading System

| Average Marks | Grade |
|--------------:|:-----:|
| 90 - 100      | A     |
| 75 - 89       | B     |
| 60 - 74       | C     |
| 40 - 59       | D     |
| Below 40      | F     |

## Python Concepts Used

This project applies the following Python concepts:

### 1. Variables

Variables are used to store the student's name and marks.

### 2. User Input

The `input()` function is used to collect information from the user.

### 3. Data Types

The program uses strings and floating-point numbers to store different types of data.

### 4. Arithmetic Operations

The program uses addition to calculate total marks and division to calculate the average.

### 5. Conditional Statements

`if`, `elif`, and `else` statements are used to determine the student's grade.

### 6. Output

The `print()` function is used to display the final result.
